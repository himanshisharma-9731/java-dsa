# 8-Week DSA Study Plan (Java, 1–2 hrs/day)

**Core resource:** Striver's A2Z DSA Course (takeUforward) — follow its problem list in order.
**Backup explainer:** Kunal Kushwaha's DSA playlist, if a concept doesn't click on first pass.

**Daily non-negotiables:**
- Write one sentence after every solve: *"This was ___ pattern because ___."*
- Every Sunday: redo 3-4 problems from earlier in the week, from scratch, no peeking.

---

## Week 1 — Logic Warmup + Arrays/Sorting

| Day | Task |
|---|---|
| 1 | CodingBat Java — Logic-1 section (all problems) |
| 2 | CodingBat Java — Array-1 + String-1 sections |
| 3 | Striver A2Z: Arrays basics (largest, second largest, check sorted, remove duplicates) |
| 4 | Striver A2Z: Rotate array, move zeros, linear search, union of two arrays |
| 5 | Striver A2Z: Missing number, max consecutive ones, single number |
| 6 | Striver A2Z: Sorting — selection/bubble/insertion (understand, don't over-drill), then merge sort |
| 7 | **Review day** — redo 4 problems from Days 3-6 from scratch. Write pattern notes. |

---

## Week 2 — Binary Search + Strings

| Day | Task |
|---|---|
| 1 | Binary search on sorted array (basic + first/last occurrence) |
| 2 | Binary search on answer — intro problems (e.g. sqrt, smallest divisor) |
| 3 | Binary search on 2D arrays / rotated sorted array |
| 4 | Strings: remove outermost parentheses, largest odd number, reverse words |
| 5 | Strings: isomorphic strings, rotate string, valid anagram |
| 6 | Strings: two-pointer string problems (valid palindrome, longest common prefix) |
| 7 | **Review day** — redo 4 problems. Attempt 1-2 Medium-tagged problems from this week's topics. |

---

## Week 3 — Recursion + Backtracking

| Day | Task |
|---|---|
| 1 | Pure recursion basics — print 1 to N, factorial, sum of array (draw the recursion tree by hand each time) |
| 2 | Recursion — subsequences / subsets generation |
| 3 | Recursion on strings — check palindrome, reverse string recursively |
| 4 | Backtracking intro — subsets II, combination sum |
| 5 | Backtracking — permutations of an array/string |
| 6 | Backtracking — N-Queens (basic version), Sudoku solver (attempt only, it's okay if slow) |
| 7 | **Review day** — redo 3 recursion + 2 backtracking problems from scratch. |

---

## Week 4 — Linked List + Stack/Queue + Sliding Window

| Day | Task |
|---|---|
| 1 | Linked list basics — traversal, insert/delete, reverse a linked list |
| 2 | Fast-slow pointer — middle of linked list, detect cycle |
| 3 | Linked list — merge two sorted lists, remove Nth node from end |
| 4 | Stack/Queue basics — implement using arrays, valid parentheses |
| 5 | Monotonic stack — next greater element, daily temperatures |
| 6 | Sliding window + two pointers — max subarray sum (fixed window), longest substring without repeat |
| 7 | **Review day** — redo 4 problems. Try 1 Medium sliding-window problem untimed. |

---

## Week 5 — Trees

| Day | Task |
|---|---|
| 1 | Tree traversals — inorder, preorder, postorder (recursive) until it's muscle memory |
| 2 | Level order traversal (BFS), iterative traversals |
| 3 | Height of tree, diameter of tree, balanced tree check |
| 4 | Lowest common ancestor (LCA), path sum problems |
| 5 | Binary Search Tree — search, insert, delete in BST |
| 6 | BST — validate BST, kth smallest element in BST |
| 7 | **Review day** — redo 3 traversal-based + 2 BST problems from scratch. |

---

## Week 6 — Graphs (basics) + Greedy

| Day | Task |
|---|---|
| 1 | Graph representation (adjacency list), BFS traversal |
| 2 | DFS traversal, number of connected components |
| 3 | Cycle detection in undirected graph (BFS/DFS based) |
| 4 | Flood fill, number of islands (grid BFS/DFS — very common placement pattern) |
| 5 | Greedy — activity selection, assign cookies |
| 6 | Greedy — merge intervals, non-overlapping intervals |
| 7 | **Review day** — redo 3 graph + 2 greedy problems from scratch. |

---

## Week 7 — Dynamic Programming (basics)

| Day | Task |
|---|---|
| 1 | 1D DP — climbing stairs, Fibonacci (do recursion → memoization → tabulation, all three, every time) |
| 2 | 1D DP — house robber, maximum subarray |
| 3 | 2D DP intro — unique paths, min path sum (grid) |
| 4 | 2D DP — 0/1 knapsack pattern intro |
| 5 | DP on strings — longest common subsequence (LCS) |
| 6 | DP on strings — edit distance (attempt only, it's a harder one) |
| 7 | **Review day** — redo 4 DP problems from scratch, all three approaches for at least one. |

## Week 8 — Mixed Practice + Mock Mode

| Day | Task |
|---|---|
| 1 | NeetCode 150 / LeetCode Top Interview 150 — mixed, **untagged**, 2 problems, 25-30 min each |
| 2 | Same as Day 1 — 2 more untagged problems |
| 3 | Same as Day 1 — 2 more untagged problems |
| 4 | Same as Day 1 — 2 more untagged problems |
| 5 | If you know target companies: pick their most-asked problem list, solve 2-3 |
| 6 | Company-tagged sheet — 2-3 more problems |

---

### If you fall behind
Borrow 1-2 days from the next week rather than skipping problems. Going slightly slower but retaining the pattern beats rushing and forgetting it by Week 5.
